# zerostreet

A low-allocation MachineLearning and Algorithmic trading framework. It is designed for high-throughput real-time services
# Installation

Install the package using Go modules:

```bash
go get github.com/ZeroGCDev/zerostreet
```

Then import the package.

For example:

```go
import "github.com/ZeroGCDev/zerostreet"
```
